# `luz-verde` documentation

The following Markdown files contain the motivations and reasoning behind the
decisions undertaken during the development of this package.

I try to give real-world examples for as many of the problems I faced as
possible; these will all be taken from the city of Santiago, Chile, where I
currently live, and where I wanted to answer the questions that motivated the
development of this package. Still, the methods (and code) should be
applicable in other cities as well, although possibly with minor
modifications.
