# `luz-verde` examples

This directory contains examples for the different functionalities of the
`luz-verde` package. These examples are all taken from the city of Santiago,
Chile. At the start of each notebook, you can choose whether to run the
example on all of Greater Santiago (slower and requires more RAM), or just on
the municipality of Providencia (part of Greater Santiago, faster and requires
less RAM). Later examples might rely on files generated by earlier examples,
so it is recommended to run them sequentially and over the same area of study
(either Greater Santiago or just Providencia).

In order to run these examples, extra packages need to be installed with `uv
sync --extra examples`. If you want to execute these scripts as Jupyter
notebooks (recommended), simply run `uv run jupytext --sync examples/*.py`.
